# GUI 冒烟测试清单

在真实桌面环境启动 `silvervpn`（Electron GUI）后，按顺序执行以下检查。
本清单覆盖最近开发的新功能，重点验证主进程 IPC 与持久化（浏览器 mock 无法覆盖的部分）。

## 准备

```bash
cd SilverVPN
npm run check           # 语法检查
npm run verify:svpn     # CLI 13 项集成测试
npm start               # 启动 GUI
```

## 1. 外观与粒子特效

- [ ] 切换 7 个主题，确认：面板悬浮光效颜色随主题变化、粒子颜色随主题变化
- [ ] 上传自定义背景图，确认背景生效；点击"清除"后恢复
- [ ] 拖动玻璃透明度滑杆，确认卡片透明程度变化
- [ ] 关闭"粒子特效"开关，粒子消失；重新打开，粒子恢复
- [ ] 调整"特效强度"，粒子数量/连线密度变化且位置不瞬移
- [ ] 重启 GUI，以上设置全部保留

## 2. 实时监控与流量统计

- [ ] 监控面板三条曲线随流量/延迟/连接数更新
- [ ] 折叠监控面板：曲线刷新暂停、按钮变 ▸；展开后恢复
- [ ] 折叠流量统计面板，重启 GUI 后折叠状态保持
- [ ] 点击流量统计"刷新"按钮，出现旋转动画后恢复
- [ ] 使用代理产生流量后，流量统计显示今天/3/7/30 天数据与按节点卡片

## 3. 端口组自定义（重点）

- [ ] 网络状态面板显示当前端口组（HTTP/SOCKS/API/Core）
- [ ] 修改基础端口为 `4880` → 点击"应用并重启" → 核心重启后端口提示更新为 4880/4881/4888/4890
- [ ] 终端执行 `svpn status`：显示"运行中（桌面 GUI 核心，HTTP 4880）"
- [ ] 终端执行 `cat ~/.config/SilverVPN/server.json`：`config.ports` 为顶层结构（非 `config.config.ports`）
- [ ] 终端执行 `svpn config ports 4780`：GUI 的 KPI/端口提示仍显示 4880（CLI 侧修改不影响运行中的 GUI；重启 GUI 后变为 4780）
- [ ] 输入非法端口（如 `999`）→ 被拦截并提示
- [ ] 输入被占用端口组 → 提示端口组被占用

## 4. 配置方案管理

- [ ] 点击"重命名"，输入新名称 → 选项卡名称更新；重启 GUI 后名称保留
- [ ] 选中当前活动方案点击"删除" → 被拒绝并提示
- [ ] 切换到其他方案后删除原方案 → 选项卡消失、`subscriptions.json` 中记录移除、对应文件被删除
- [ ] 点击"打开配置"按钮 → 文件管理器打开配置目录
